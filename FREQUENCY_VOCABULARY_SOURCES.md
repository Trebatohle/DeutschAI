# Frequency vocabulary sources and attribution

The frequency-informed level bands in the expanded German drill use the German
OpenSubtitles 2018 frequency list published in
[hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords)
(file: `content/2018/de/de_50k.txt`).

- Source project: Hermit Dave, FrequencyWords
- Corpus: OpenSubtitles 2018
- Dataset licence: **CC BY-SA 4.0**
- Licence text: https://creativecommons.org/licenses/by-sa/4.0/

The app derives approximate learning bands from the corpus rank:

| Band | Approximate frequency rank |
| --- | ---: |
| A1 | 1–3,000 |
| A2 | 3,001–9,000 |
| B1 | 9,001–25,000 |
| B2 | Remaining or unranked entries |

These are **frequency-informed estimates**, not official Goethe-Institut CEFR classifications.
The corpus contains subtitles, so its ranking is a useful proxy for conversational exposure,
not a perfect measurement of all spoken German.

The German–Czech meanings and example sentences in the app's curated vocabulary and learning
catalogues are maintained as app learning content; the frequency list is used for relative
commonality and the estimated level bands.
